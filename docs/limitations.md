# 已知限制

按"会不会被面试官追问"排序，逐条给出可回答的边界。

| 限制 | 事实 | 影响 |
| --- | --- | --- |
| 闭环固定并发 | 每档固定 N 条请求、固定并发，非泊松到达 | 只能声称"该窗口的完成速率"，不能声称生产 QPS |
| 单模型单卡 | Qwen2.5-1.5B、TP=1 | 不外推到 8B / 70B / 多卡；只保留 KV 公式外推 |
| 样本量 | TTFT 分位数基于 N 条请求；ITL 分位数基于 N×(n_out−1) 个间隔 | TTFT 的 P95 粗糙，ITL 的 P99 稳定，二者不可并列比较 |
| 跨会话可比性 | client 侧受宿主负载影响 | 跨会话只比 engine 侧 |
| 尾波 | 固定 N 时最后一批可能未填满 | 横轴用有效并发，或取 N 远大于 B |
| 随机 prompt | 输入为随机 token id，不代表真实文本分布 | 不讨论语义/长度分布对缓存的影响，除 E2 的人造共享前缀 |
| Prefix Cache 底噪 | warmup 与首条压测请求同 prompt，产生约 1008 token 命中 | E2 的结论以"相对底噪的增量"表述 |
